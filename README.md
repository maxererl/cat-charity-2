# QRKot

QRKot - приложение для вымышленного благотворительного фонда поддержки котиков. Фонд собирает пожертвования на корм, медицинское обслуживание, организацию приютов и другие нужды кошачьей популяции.

В приложении можно открывать целевые проекты, то есть сборы конкретной суммы под конкретную задачу, и принимать пожертвования. Пожертвование отправляется в фонд, а не в конкретный проект, и автоматически распределяется по открытым проектам.

## Как работает инвестирование

У проекта есть название, описание и сумма, которую нужно собрать. Когда сумма собрана, проект закрывается.

Каждое новое пожертвование попадает в самый старый открытый проект. Если пожертвование больше, чем нужно этому проекту, проект закрывается, а остаток уходит в следующий по старшинству открытый проект. Если открытых проектов не осталось, остаток ждёт появления нового проекта.

При создании нового проекта все нераспределённые пожертвования автоматически вкладываются в него, начиная с самых старых.

Создание проекта или пожертвования и последующее распределение средств выполняются в одной транзакции: сохранение происходит одним вызовом session.commit() в конце.

## Стек

Python, FastAPI, SQLAlchemy 2.0 (асинхронный режим), SQLite (aiosqlite), Alembic, Pydantic.

## Установка и запуск

Создайте и активируйте виртуальное окружение, затем установите зависимости:

```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

В Windows активация выполняется командой venv\Scripts\activate.

Примените миграции, чтобы создать базу данных:

```
alembic upgrade head
```

Запустите сервер:

```
uvicorn app.main:app --reload
```

Документация Swagger будет доступна по адресу http://127.0.0.1:8000/docs, ReDoc - по адресу http://127.0.0.1:8000/redoc.

## Настройки

По умолчанию используется база данных SQLite в файле fastapi.db в корне проекта. Адрес подключения и другие параметры можно переопределить через переменные окружения или файл .env, например:

```
DATABASE_URL=sqlite+aiosqlite:///./my_database.db
```

## Эндпоинты

```
GET    /charity_project/               список всех целевых проектов
POST   /charity_project/               создать целевой проект
PATCH  /charity_project/{project_id}   редактировать целевой проект
DELETE /charity_project/{project_id}   удалить целевой проект
GET    /donation/                      список всех пожертвований
POST   /donation/                      создать пожертвование
```

Ограничения для проектов:

- название уникально, длина от 5 до 100 символов;
- описание не короче 10 символов;
- требуемая сумма - целое число больше 0;
- закрытый проект нельзя редактировать;
- нельзя установить требуемую сумму меньше уже вложенной;
- нельзя удалить проект, в который уже вложены средства.

Сумма пожертвования - целое число больше 0, комментарий необязателен.

## Структура проекта

```
app/
    api/
        endpoints/      эндпоинты проектов и пожертвований
        routers.py      подключение роутеров и теги
        validators.py   проверки, которые вызываются из эндпоинтов
    core/
        config.py       настройки приложения
        db.py           подключение к БД, базовая модель, сессия
    crud/               операции с БД
    models/             ORM-модели CharityProject и Donation
    schemas/            Pydantic-схемы
    services/
        investment.py   распределение средств между проектами и пожертвованиями
    main.py             создание приложения FastAPI
alembic/                миграции
```
